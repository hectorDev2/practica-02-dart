# Práctica 02 — Tipos de datos en Dart

Solución de la guía sobre `List`, `Map`, `Set`, tipos primitivos, null safety,
records y enums.

## Ejecutar

Requiere Dart 3.0 o superior.

```bash
dart run bin/main.dart
dart run test/guide02_test.dart
```

Enlace directo verificable en [DartPad](https://dartpad.dev/?id=40f1337e98900f5eb381175cdfb21fd6&run=true).

## Ejercicios resueltos

1. **List:** combinación ordenada de dos listas enlazadas.
2. **Map:** intersección de dos arreglos conservando multiplicidades.
3. **Set:** asignación de frutas a la cesta disponible más a la izquierda.
